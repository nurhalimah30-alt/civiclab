# CIVICLAB — Custom Website

Website custom CivicLab untuk digitalisasi layanan Laboratorium PPKn.

## File
- `index.html` — halaman utama
- `style.css` — desain dan responsif
- `script.js` — tombol/link dan menu mobile

## Yang sudah tersedia
- Beranda profesional
- Profil Laboratorium
- Layanan Laboratorium
- Tombol pengajuan penggunaan laboratorium
- Bahan Ajar & Media Pembelajaran
- SOP LAB
- E-Katalog (siap diisi setelah data fasilitas tersedia)
- Evaluasi CivicLab
- Kontak
- Tampilan desktop dan HP

## Tiga hal yang perlu dilengkapi
Buka `script.js`, lalu ganti:
1. `bookingForm` dengan link Google Form Pengajuan Penggunaan Laboratorium yang sudah Ibu buat.
2. `evaluationForm` dengan link Google Form Monitoring & Evaluasi nanti.
3. `teachingMaterial` dengan link bahan ajar setelah bukunya selesai.
4. `sopDocument` dengan link dokumen SOP setelah final.

## Publikasi gratis
Website ini berupa file HTML/CSS/JS biasa sehingga dapat dipublikasikan di layanan static hosting seperti GitHub Pages atau Cloudflare Pages tanpa membeli hosting berbayar.

Untuk domain sendiri seperti `civiclab.id`, domain dapat dibeli kemudian jika diperlukan.
